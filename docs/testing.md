# StegoVault Testing & Verification Strategy

StegoVault utilizes a rigorous automated testing architecture covering low-level cryptography, binary serialization, spatial pixel manipulation, statistical steganalysis, API endpoints, and file upload security.

---

## 1. Test Architecture & Environment

To provide sub-second test execution without compromising security in production, StegoVault introduces an environment-aware PBKDF2 iteration configuration:
- **Production (`APP_ENV=production`):** $600{,}000$ PBKDF2 rounds (aligned with OWASP).
- **Testing (`APP_ENV=testing`):** $1{,}000$ PBKDF2 rounds.

Because iteration counts are embedded directly in the 64-byte container header (`uint32` at offset 8), test vectors and production images can be decrypted deterministically across any environment.

## 2. Test Suite Breakdown (43 Test Cases)

| Test Module | Focus Area | Covered Behaviors |
| :--- | :--- | :--- |
| `tests/test_crypto.py` | Cryptographic Subsystem | Deterministic key derivation, password uniqueness, AES-256-GCM roundtrip, wrong password rejection, ciphertext tampering detection, auth tag modification rejection. |
| `tests/test_payload.py` | Binary Container | 64-byte header packing/unpacking, CRC32 header verification, corrupted CRC rejection, non-StegoVault magic byte rejection, truncated payload handling. |
| `tests/test_steganography.py` | LSB Engine | Exact capacity calculation, capacity evaluation (sufficient / insufficient), overflow prevention, non-destructive RGB/RGBA encoding, decode roundtrip, decode rejection on clean images. |
| `tests/test_steganalysis.py` | Forensics Metrics | Shannon byte entropy bounds ($[0, 8]$), Shannon bit entropy bounds ($[0, 1]$), Chi-Square PoV test, LSB 0/1 distributions, 256-bin RGB histograms, Pearson correlation matrix, trailing data detection past legal EOF. |
| `tests/test_risk_engine.py` | Risk Scoring | Clean image baseline scoring (low risk), StegoVault container detection (critical risk), trailing EOF data penalty (+45 risk). |
| `tests/test_security.py` | Boundary Security | Magic byte enforcement against fake extensions, rejection of lossy formats (JPEG), 20MB file size ceiling enforcement, Pillow decompression bomb defense, path traversal sanitization. |
| `tests/test_dataset.py` | Synthetic Dataset | Validates all 7 synthetic test images generated by `generate_test_data.py`. |
| `tests/test_api.py` | REST API | Health check, real-time capacity calculation endpoint, encode and decode HTTP roundtrips, analyzer execution, report persistence, and export. |

## 3. Synthetic Test Dataset (`test_data/`)

A dedicated script (`scripts/generate_test_data.py`) generates a reproducible, safe synthetic dataset for manual testing and automated validation:

1. **`normal.png` ($256 \times 256$ RGB):** Natural gradient photograph baseline. Expected Risk: **Clean / Minimal ($0 \le \text{Score} \le 20$)**.
2. **`stego_low.png` ($256 \times 256$ RGB):** StegoVault container with short message ($< 1\%$ capacity). Expected Risk: **Critical ($> 80$)** due to StegoVault container detection, but minimal visual/statistical footprint.
3. **`stego_medium.png` ($256 \times 256$ RGB):** StegoVault container with moderate message length.
4. **`stego_high.png` ($256 \times 256$ RGB):** Dense payload occupying $> 50\%$ capacity. Triggers strong Chi-Square PoV equalisation ($\chi^2 \to 0$, $p \to 1.0$) and high bit entropy ($H \approx 1.0$).
5. **`corrupted.png` ($256 \times 256$ RGB):** Valid container where random LSB bits have been flipped. Tests tamper detection and authentication rejection.
6. **`metadata_test.png` ($256 \times 256$ RGB):** Clean PNG containing auxiliary chunks (`tEXt` comment and timestamp). Tests metadata inspection.
7. **`trailing_data_test.png` ($256 \times 256$ RGB):** Standard PNG with 191 bytes of covert binary payload appended past the `IEND` chunk. Tests EOF boundary detection.

## 4. Running the Tests

### Backend Pytest Suite
```bash
cd backend
.venv\Scripts\pytest -v
```

### Full Verification Suite (Windows)
```bash
scripts\run_tests.bat
```
Executes:
1. Backend test suite (43 tests).
2. Synthetic dataset generation.
3. Frontend TypeScript check & Vite production build.
